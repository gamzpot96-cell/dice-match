# Dice Match

나무 질감의 주사위를 활용하는 2인 전략 웹게임입니다. **AI 대전**, **한 기기에서의 2인 로컬 대전**, **초대 코드로 진행하는 온라인 대전**을 제공합니다.

## 현재 구현 상태 — v4.5

- **AI 대전 (`ai.html`)**: 쉬움(무작위), 보통(공격·점수 중심), 어려움(상대의 다음 턴 가능성까지 고려) 난이도를 제공합니다. 공격 보상으로 얻은 낮은 숫자 실드는 상대방 필드 방해를 우선 고려합니다. AI는 외부 모델 API를 호출하지 않는 규칙 기반 프로그램입니다.
- **2인 로컬 대전 (`game.html`)**: 한 브라우저에서 두 플레이어가 번갈아 플레이할 수 있습니다.
- **온라인 대전 (`online.html`, `online-game.html`)**: Cloudflare Workers 및 Durable Objects 기반으로 방 생성·참가, 6자리 초대 코드, 양쪽 경기 준비, 시작 카운트다운과 게임 상태 동기화를 지원합니다.
- **재접속 보호**: 경기 중 연결이 끊기면 60초 동안 일시 정지합니다. 제한 시간 내 복귀하면 경기를 재개하고, 초과하면 연결을 유지한 플레이어가 부전승합니다. 일반 브라우저는 저장된 인증 정보로 자동 복귀할 수 있으며, 시크릿 창을 모두 닫았을 경우 개인 복귀 코드가 필요할 수 있습니다.
- **효과음**: 주사위 등장·배치·공격·리롤·실드·게임 종료 등에 효과음을 사용합니다. BGM은 사용하지 않습니다.

v4.5 기준 Node.js 자동 테스트 **160개 통과, 실패 0개**입니다. Vercel Production 배포 후 PC·모바일 실행, AI 대전 시작, 온라인 서버 연결 및 서로 다른 기기 간 온라인 대전·게임 상태 동기화를 직접 확인했습니다. 자동 테스트와 실기기 점검은 모든 환경에서 오류가 없음을 보장하지 않습니다.

## 게임 규칙 요약

- 게임판은 플레이어마다 **3개 라인**으로 구성됩니다.
- 같은 라인에서 같은 숫자 `n`이 **1개면 `n`점, 2개면 `3n`점, 3개면 `5n`점**입니다. 실드도 점수 조합에 포함됩니다.
- 각 경기의 선공은 무작위로 정합니다. 선공자는 시작 실드를 먼저 배치합니다.
- 일반 주사위를 놓아 같은 라인의 상대 일반 주사위를 공격하면 해당 숫자의 상대 일반 주사위와 공격 주사위가 제거됩니다. **실드 주사위는 공격으로 제거되지 않습니다.**
- 공격 성공 후 얻는 보상 실드는 배치할 수 있는 자신의 필드 또는 상대 필드에 놓을 수 있습니다. 보상 실드를 놓는 행위는 추가 연쇄 공격을 일으키지 않습니다.
- 리롤은 **플레이어당 한 경기 1회**이며 시작 실드 또는 일반 주사위에 사용할 수 있습니다. 공격 보상 실드는 리롤할 수 없습니다. 리롤에서는 기존 숫자와 다른 후보가 제시되고 둘 중 하나를 선택합니다.
- 승패는 **승리한 라인 수 → 총점 → 최고 라인 점수** 순서로 비교하며, 모두 같으면 무승부입니다.

상세 규칙: [`docs/rules.md`](docs/rules.md)

## 실행 방법

### AI·로컬 대전 (Windows 11 / VS Code)

1. 이 프로젝트 폴더를 VS Code로 엽니다.
2. Live Server 등의 로컬 정적 웹 서버를 실행해 `index.html`을 엽니다.
3. AI 대전 또는 2인 로컬 대전을 선택합니다.

게임 화면은 HTML·CSS·JavaScript를 사용하므로 별도의 Python 서버가 필요하지 않습니다.

### 온라인 대전

온라인 대전은 **브라우저 화면과 별도로 배포된 Cloudflare Worker 서버**가 필요합니다.

- 브라우저 설정 파일: `js/online-config.js` — `window.DICE_MATCH_SERVER_URL`에 배포된 Worker의 HTTPS 주소를 지정합니다. 이 주소는 공개 접속 주소이지 비밀키가 아닙니다.
- 서버 코드: `worker/index.mjs`, `worker/engine.mjs`
- Worker 배포 설정: `worker/wrangler.jsonc`

이미 설정된 서버를 업데이트해야 할 때만, Cloudflare 계정으로 인증된 터미널에서 다음 명령어를 사용합니다.

```powershell
cd worker
npx wrangler deploy
```

계정 ID를 자동으로 조회할 수 없으면 본인 계정의 `CLOUDFLARE_ACCOUNT_ID` 환경변수를 설정해야 합니다. **인증 토큰, 개인 복귀 코드 또는 비밀키를 GitHub에 올리지 마세요.**

## 자동 테스트

Node.js가 설치된 Windows 11 PowerShell에서 프로젝트 루트로 이동해 실행합니다.

```powershell
node --test tests/*.test.js
```

v4.5 기준 검증 결과: `tests 160`, `pass 160`, `fail 0`.

자동 테스트 통과는 모든 운영 환경에서 오류가 없다는 보장은 아닙니다. 배포 후에는 실제 서로 다른 기기에서 온라인 대전과 재접속을 확인해야 합니다.

## 설계 및 주의 사항

- AI 판단은 규칙 기반이며 외부 유료 AI API를 사용하지 않습니다.
- 온라인 대전의 게임 상태와 인증 검증은 서버에서 처리합니다. 방 초대 코드만으로 기존 플레이어의 자리를 탈취하지 못하도록 개인 복귀 코드로 확인합니다.
- 일반 브라우저의 자동 복귀에는 브라우저 저장소가 사용됩니다. 공용 컴퓨터에서는 경기 종료 후 정상적으로 나가고 브라우저 데이터를 관리하세요.
- 주사위 생성 방식과 게임 확률은 v4.5에서 변경하지 않았습니다.
- 사용된 효과음의 생성 방식과 사용 관련 기록은 [`docs/sound-license.md`](docs/sound-license.md)를 참고하세요. 게임 화면의 Gmarket Sans 글꼴은 외부 CDN에서 불러오며, 해당 글꼴의 별도 라이선스 조건이 적용됩니다.
