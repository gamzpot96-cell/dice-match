# Dice Match — STEP 6 온라인 대전 설계 v0.1

## 현재 구현 범위
- 온라인 대기실 정적 화면, 초대 코드 문법 검사, 온라인 게임 메시지 형식 검증.
- 실제 서버, 방 생성 API, 실시간 접속, 게임 동기화, 초대 코드 발급은 **미구현**.
- AI 대전과 로컬 2인 대전 코드를 변경하지 않음.

## 서버 연결 후 사용할 설계
1. 서버에서 방을 생성하고 무작위 6자리 코드와 방장/참가자별 **별도 비밀 접속 토큰** 발급.
2. 양쪽이 준비되면 서버에서 파랑·빨강 플레이어 배정 및 선공자 무작위 추첨. 선공자만 시작 실드 지급.
3. 서버가 난수를 생성하고 공통 `js/engine/game.js`의 `roll`, `reroll`, `place`, `chooseReroll` 수행.
4. 클라이언트는 `type`, `version`, `player`, `line` 또는 `chooseNew`만 요청하며 주사위 값을 임의로 제출하지 못함.
5. 서버가 접속 토큰, 현재 차례, 게임 상태 버전, 규칙상 허용된 수를 확인한 뒤 상태 변경·전파.
6. 연결 끊김 시 재접속 토큰으로 상태 재동기화. 서버에 방 만료 시간과 탈퇴 정책을 추가할 예정.
7. 레이트 리밋, 비밀 토큰 보호, 방 코드 대입 방지, 원자적 상태 업데이트 필요.

## 플랫폼
Vercel은 정적 프런트 배포용으로 적절합니다. 실시간 게임의 일관성을 위해 별도의 공유 저장소와 실시간 메시지 전달 방식이 필요합니다. 공급자 및 배포 구성을 아직 결정하지 않았으므로 특정 백엔드와 요금이 확정되었다고 주장하지 않습니다.

## UI 및 규칙
- 세로 중앙선, 동일 숫자 그룹, 실드 테두리 및 공격 애니메이션 유지.
- 내 턴만 `주사위 돌리기` 활성화. 서로의 준비 주사위 공개.
- 각자의 리롤은 게임당 1회이며 새 숫자는 기존 눈과 반드시 다름.
- 리롤/공격 애니메이션과 네트워크 상태를 분리해 재전송으로 이중 배치되지 않도록 함.
