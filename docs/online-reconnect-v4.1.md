# Dice Match — 온라인 재접속 보호 v4.1

## 동작
- 경기 중 한 명의 WebSocket 연결이 끊기면 서버에서 60초 타이머 시작.
- 게임 행동은 서버가 409로 거부하고 양쪽의 게임판 중앙에 남은 시간 표시.
- 60초 내 양쪽 연결이 회복되면 저장된 게임 상태와 리롤 횟수를 유지한 채 재개.
- 한 명만 계속 연결되어 있고 상대방이 제한시간을 넘기면 남은 플레이어가 부전승.
- 양쪽 모두 연결을 잃어 제한시간이 지나면 승자를 정하지 않고 방 종료.
- 경기 중 `로비로 나가기`를 확인하면 명시적 경기 포기로 상대방에게 즉시 부전승.
- 서버는 Durable Object alarm으로 만료를 판정하며 브라우저 시계에 의존하지 않음.

## 배포
1. `worker/index.mjs`를 기존 프로젝트에 덮어쓰기.
2. `online-game.html`, `js/online-game.js`, `css/game.css`를 동일 경로에 덮어쓰기.
3. `js/online-config.js`는 덮어쓰거나 초기화하지 않음.
4. `C:\\workspace\\dice-match\\worker`에서 `npx wrangler deploy`를 실행하여 기존 Worker 갱신.
5. 일반 브라우저와 시크릿 브라우저에서 새 게임방을 만들어 검증.

## 확인할 점
- 경기 도중 한쪽 창을 닫으면 다른 쪽에 1:00부터 감소하는 카운트다운 표시.
- 닫은 창을 60초 안에 다시 열고 재접속하면 일시 정지 해제 및 기존 상태 복원.
- 60초를 넘기면 부전승으로 결과 오버레이 표시.
- 두 창을 모두 닫으면 제한시간 경과 후 방 종료.
- 테스트 중 실시간 서버에 새로운 Worker를 배포하지 않으면 변경 사항이 반영되지 않음.

## 주의
- 브라우저나 네트워크의 WebSocket 종료 감지 시점은 즉시가 아닐 수 있음.
- 클라이언트에서 재접속에 실패하면 새로고침으로 복구 시도.
- 서버 측 시간초과 동작은 자동 테스트했지만 실제 두 브라우저/인터넷 환경에서 추가 검증 필요.
