# Dice Match v4.5 — 낮은 보상 실드 방해 배치

- 공격 성공 후 받는 보상 실드(처음 주어지는 시작 실드가 아님)에만 적용합니다.
- 보상 실드 눈이 1 또는 2이면 상대 보드에 놓을 수 있는 안전한 라인을 먼저 평가합니다.
- 안전한 라인은 해당 눈과 같은 숫자의 상대 주사위가 없는 라인입니다. 상대 조합을 강화하지 않도록 합니다.
- 안전한 상대 라인이 없으면 기존 합법적 배치 전체를 평가합니다. 보상 실드 3은 상대 방해 배치 점수에 가산점만 주어 예외적인 자기 점수 이득도 반영합니다.
- 기존 쉬움 난이도의 랜덤 선택, 일반 주사위 배치, 리롤, 온라인/로컬 게임 엔진의 규칙은 변경하지 않습니다.
