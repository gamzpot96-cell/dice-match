# Dice Match — 확정된 규칙 요약 v1.2

- 1대1 턴제, 플레이어별 3라인, 라인별 최대 3개 주사위.
- 눈 1~6, 같은 눈 1개는 n점, 2개는 3n점, 3개는 5n점.
- 턴 시작 시 주사위를 자동으로 굴리며, 별도의 굴리기 버튼은 사용하지 않음.
- 선공·후공은 매 경기 무작위 결정(파랑/빨강 모두 선공 가능). 선공자 첫 턴: 무작위 실드 주사위 1개를 자기 보드에만 배치 후 종료.
- 일반 주사위는 자신의 빈칸이 있는 라인에 배치. 같은 라인 상대 일반 주사위와 숫자가 일치하면 자동 공격.
- 공격 시 해당 라인의 상대 일반 주사위 중 같은 눈을 모두 제거. 자기 공격 주사위도 사라짐. 실드 주사위는 제거 면역.
- 공격 성공 후 무작위 실드 1개를 즉시 굴려 같은 턴에 반드시 배치. 자기/상대 보드 모두 가능하며, 상대 보드에 놓은 실드는 상대 점수로 계산.
- 실드도 일반 주사위와 점수 조합을 공유하나 실드 배치 자체는 공격을 일으키지 않음.
- 실드를 배치할 수 있는 빈칸이 하나도 없으면 배치를 생략하고 턴 종료.
- 리롤은 일반 주사위 또는 선공자의 첫 시작 실드에 사용 가능. 플레이어별 게임당 합계 1회만 허용하며, 원래 눈과 새 눈 중 선택. 공격 보상 실드는 리롤 불가.
- 자기 보드가 꽉 차면 공격도 불가하며 일반 턴을 건너뜀.
- 최대 턴 제한 없음. 턴 처리가 끝나고 양쪽 보드가 모두 가득 차면 종료.
- 승패 순위: 이긴 라인 개수 → 전체 점수 → 최고 단일 라인 점수 → 무승부. 라인 동점은 승리로 계산하지 않음.

**주의:** 장기전과 종료 가능성은 추후 실제 게임 엔진 테스트에서 확인해야 합니다.

## v1.1 변경 이력

- 동일한 숫자 3개 점수: 종전 `6n`에서 **`5n`**으로 수정 (숫자 4 세 개=20점, 숫자 5 세 개=25점).
- 그 외 게임 규칙은 v1.0과 동일합니다.

## v1.2 변경 이력

- 선공자 시작 실드도 리롤 가능(공용 1회 소모).
- 모든 플레이어의 주사위는 턴 시작 시 자동 굴림. 공격 보상 실드도 공격 판정 직후 자동 생성.

## 선공 무작위 결정 (v1.3)

- AI 대전, 2인 로컬 대전, 온라인 대전 모두 선공·후공은 매 경기 무작위로 결정합니다.
- 색상(파랑/빨강)은 선공과 무관합니다. 매 경기 새로 추첨합니다.
- 시작 실드 주사위는 무작위로 선정된 선공자만 받습니다.
- 온라인 대전 구현 시 선공 추첨은 서버에서 한 번만 수행하고 두 이용자에게 동일하게 전달해야 합니다. (온라인 기능은 아직 미구현)
