# Dice Match v4.3 — 자동 복귀 및 대기실 복귀 코드 정리

- 일반 Chrome 브라우저는 경기 인증 정보(방 코드, 자리, 인증 토큰, 복귀 코드)를 sessionStorage와 localStorage에 보관합니다. 기존 탭을 닫고 같은 브라우저에서 다시 `online.html` → 시작하기를 누르면 서버에 인증된 방 상태를 확인해 경기 화면으로 이동합니다.
- 경기 화면을 열어둔 채 WebSocket 연결이 끊어지면 2초 간격으로 재접속을 시도합니다. 서버의 기존 60초 제한과 부전승 판정은 그대로 유지됩니다.
- 경기 종료, 명시적 나가기, 대기실 종료 시 두 저장소의 인증 정보를 삭제합니다.
- 대기실의 복귀 코드는 경기 준비/나가기 버튼 **아래** 작은 접이식 상세 영역에 배치합니다.
- 시크릿 창 **전부 종료** 시 Chrome에서 비공개 저장소가 삭제되므로 자동 복귀할 수 없습니다. 이 경우에만 사전에 보관한 개인 복귀 코드와 방 코드로 복귀해야 합니다. 복귀 코드는 타인에게 알려주지 마세요.
- 공용 기기에서 일반 브라우저를 사용하면 같은 브라우저 프로필 사용자에게 복귀 인증이 남을 수 있으니 사용 후 명시적으로 나가거나 브라우저 데이터를 지우세요.
- Cloudflare Worker 코드는 변경하지 않았으므로 새 Worker 배포는 필요 없습니다.
