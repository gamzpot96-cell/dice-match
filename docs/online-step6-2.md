# STEP 6-2 — 온라인 대기실 (코드 발급 및 참여)

**구현 완료 범위:** Cloudflare Worker + SQLite-backed Durable Object 방 생성/입장, 6자리 코드, 방장/참여자 임의 접근 토큰, 두 명 정원, WebSocket 접속 상태 갱신. 브라우저 새로고침 후 같은 탭에서 접속 복원 시도.

**아직 불가능:** 게임 시작/주사위 굴리기/공격/턴 동기화, 외부 인터넷 배포 테스트, 강제 퇴장/방 폐쇄, 전체 클라이언트 공격 방어. 방 코드는 초대용이며 사용자 계정이나 암호가 아닙니다.

## 로컬 시험 — Windows 11, VS Code

Node.js 설치가 필요합니다. 두 개의 VS Code 터미널을 사용합니다.

1. 프로젝트 `dice-match/worker` 폴더에서 터미널 실행:

   ```powershell
   cd worker
   npm install
   npx wrangler dev --port 8787
   ```

   예상 결과: `http://127.0.0.1:8787`에서 Worker 구동.

2. `dice-match/js/online-config.js`를 열어 주소를 다음과 같이 수정:

   ```javascript
   window.DICE_MATCH_SERVER_URL = 'http://127.0.0.1:8787';
   ```

3. 다른 터미널에서 프로젝트 루트로 돌아와 정적 웹 서버를 실행합니다. Python 설치 시:

   ```powershell
   py -m http.server 5500
   ```

   예상 결과: `Serving HTTP on ... port 5500`.

4. 브라우저 두 개(일반/시크릿 창)를 열고 `http://127.0.0.1:5500/online.html` 접속. 첫 브라우저에서 `방 생성`, 두 번째에서 코드로 `방 입장`을 누릅니다. 두 창에서 접속 상태가 갱신되어야 합니다.

5. 게임 플레이는 여전히 불가능합니다. 게임을 하려면 기존 `ai.html` 또는 `game.html`을 사용합니다.

## 실제 서버 배포 (요청 전까지 미진행)

Cloudflare 계정에서 무료 Workers 환경을 사용한다는 조건에서 `worker` 폴더의 `npx wrangler login` 이후 `npx wrangler deploy` 명령을 사용할 수 있습니다. 배포된 `https://...workers.dev` 주소를 `js/online-config.js`에 설정하고, 웹사이트를 Vercel Hobby 등 정적 호스팅으로 배포합니다. 계정 연결과 실제 배포는 수행하지 않았습니다.

무료 한도를 넘으면 서비스가 제한되거나 서비스 정책에 따라 비용이 달라질 수 있으므로, **유료 요금제·유료 애드온으로 변경하지 말고 사용량을 확인**해야 합니다. SQLite-backed Durable Object는 Cloudflare 내부 저장 기능이며 **프로젝트 별도 DB 서버를 구매하거나 SQLite 파일을 따로 설치하는 것은 아닙니다**. 기존 AI/로컬 게임에는 DB를 추가하지 않습니다.

## 보안 및 운영 한계

- 임의 6자리 코드: 공개 게시를 피하세요. 코드만으로 빈 방에 합류할 수 있습니다.
- 2인 제한: 방장과 참여자 토큰을 생성·보관하고, 방 상태는 해당 토큰으로만 확인합니다. 웹소켓 연결은 토큰이 있는 사용자만 받습니다.
- 플레이 명령: 허용하지 않습니다. 서버 검증을 구현하기 전까지 클라이언트가 게임 결과를 보낼 수 없습니다.
- 방 유효 기간: 생성 후 6시간. 현재 자동 삭제 기능은 없습니다(만료 방 재사용 불가).
- 새로고침 복구: 동일 브라우저 탭의 sessionStorage에 있는 접속 정보로 시도합니다. 시크릿 창 종료나 저장소 삭제 시 복원이 불가능할 수 있습니다.
- 네트워크 끊김: 접속 상태가 바뀌지만 자동 재연결은 하지 않습니다. 새로고침하여 복구합니다.
- 실제 Cloudflare 서비스 연결·동시접속·비용 한도 검증은 아직 하지 않았습니다.
