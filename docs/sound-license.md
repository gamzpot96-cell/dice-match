# Dice Match 효과음 제작 및 사용 기록 (v2.2)

- 외부 사이트에서 다운로드한 음원이나 제3자 녹음·작곡의 샘플을 사용하지 않았습니다.
- 이 프로젝트에 포함된 7개 MP3는 2026-11-05, NumPy를 이용하여 순수한 사인파와 의사난수 노이즈를 합성해 제작했습니다.
- 사용한 제3자 음원: 없음. 샘플링 원본: 없음. 출처 표시가 필요한 외부 음원: 없음.
- 프로젝트에 포함된 합성 효과음은 Dice Match 프로젝트 내에서 무상으로 사용할 수 있도록 제공됩니다. 이는 제3자의 상표나 다른 권리에 대한 법적 보증이 아닙니다.
- 소리: dice-appear, dice-reroll, dice-place, dice-hit, dice-fall, shield-gain, game-finish.
- 배경음악(BGM): 미사용.
- 브라우저는 최초 사용자 클릭/키보드 입력 전 자동 재생을 제한할 수 있습니다. 이 경우 첫 자동 주사위의 등장 소리는 들리지 않을 수 있지만 게임은 정상 진행됩니다.
- 음소거와 볼륨 조절은 사용자 브라우저에 보관하며 게임 규칙에는 영향을 주지 않습니다.
- WAV 대신 용량이 작은 MP3로 배포합니다.

## 재현 방법

`tools/generate_sounds.py`는 파이썬 NumPy와 FFmpeg 설치 환경에서 7개 MP3를 동일한 절차로 다시 만들기 위한 스크립트입니다.

## v2.4 공격음 조정

- `dice-hit.mp3`만 재합성: 짧은 선명한 플라스틱 접촉음과 가벼운 잔향('따악~')을 사용합니다.
- 외부 녹음·샘플은 사용하지 않았으며 `assets/sounds/generate-plastic-hit.py`로 재현 가능합니다.
- 나머지 6개 음원과 게임 규칙, 타이밍, UI는 변경하지 않았습니다.

## v2.6 공격음 확정

- `assets/sounds/dice-hit.mp3`를 사용자가 미리 듣고 선택한 **돌 충돌음 -7dB** 버전으로 교체했습니다.
- 외부 샘플을 사용하지 않고 직접 합성한 미리듣기 음원입니다.
- 이전 v2.4 플라스틱 충돌음은 이 버전의 실제 게임 재생 음원이 아닙니다.
- 다른 6개 효과음과 게임 동작, 화면, 볼륨 설정은 변경하지 않았습니다.
