# Dice Match v4.0 — 온라인 대기실 준비·코드 관리

## 변경 기능

1. `경기 준비` / `대기실 나가기` 버튼 크기와 너비 동일
2. 상대방 미입장 시에도 `경기 준비` 표시 (비활성)
3. 대기실에서 어느 한쪽이 나가거나 연결을 끊으면 기존 코드 폐기 및 초기 입장 화면 복귀
4. 방장 `새 코드 발급`: 기존 코드 폐기, 새 코드 발급. 이미 입장한 참여자는 초기 화면으로 돌아감
5. 각자 `경기 준비`를 눌러야 다음 단계 진행. 상대방 준비 상태 표시
6. 먼저 준비한 사용자는 3초간 버튼 비활성, 이후 `준비 취소` 사용 가능. 둘 다 준비하면 취소 불가
7. 두 사람 준비 완료 시 양쪽에 `3 → 2 → 1 → START` 표시 후 서버에서 게임 시작을 확인하고 진입

## 필수: 적용 순서 (Windows 11)

이번 수정은 Cloudflare Worker 서버와 로컬 웹 파일을 **함께** 수정해야 합니다.

1. 현재 `C:\workspace\dice-match`를 백업합니다.
2. ZIP의 `worker/index.mjs`, `online.html`, `js/online-lobby.js`, `css/online.css` 파일을 각 원래 경로에 덮어씁니다.
3. ZIP의 `tests` 폴더는 개발용 테스트를 실행하려면 동일한 경로에 덮어씁니다.
4. `js/online-config.js`는 ZIP에 **포함되어 있지 않습니다**. 배포된 서버 주소를 그대로 유지하세요.
5. VS Code 터미널에서 아래 명령어로 테스트합니다.

   ```powershell
   cd C:\workspace\dice-match
   npm test
   ```

6. Cloudflare Worker도 업데이트해야 변경된 `/ready`, `/leave`, `/rotate` API가 작동합니다. 아래 명령어는 **실제 서버를 재배포합니다**.

   ```powershell
   cd C:\workspace\dice-match\worker
   $env:CLOUDFLARE_ACCOUNT_ID = "f07a8a06e302b04e97faa3afeccaae34"
   npx wrangler deploy
   ```

7. 두 Chrome 창에서 `Ctrl + Shift + R`로 새로고침하고 **새 방을 생성**해서 테스트하세요. 이전 버전에서 생성한 방을 재사용하지 마세요.

## 테스트 순서

- 방장 단독 대기: `경기 준비` 비활성, `대기실 나가기`와 크기 동일
- 참가자 접속: 두 사람 모두 `경기 준비` 활성
- 방장 먼저 준비: 상대 화면에 준비 상태 표시, 방장은 3초 이후 `준비 취소` 가능
- 두 사람 준비: 3·2·1·START 뒤 두 화면 게임 동기화
- 참가자 대기실 나가기: 양쪽 기존 방 폐기, 오래된 코드 입장 실패
- 방장 새 코드 발급: 기존 코드 입장 실패, 새 코드 입장 가능
- 경기 중 새로고침: 기존 세션 복구 가능

## 주의 사항

- 대기실에서 브라우저 창을 닫거나 새로고침해 WebSocket 연결이 끊기면 방이 폐기될 수 있습니다. 게임이 시작된 뒤에는 재접속을 허용합니다.
- 개발 테스트는 서버·브라우저 시계 차이가 있을 수 있어 실제 2대 PC의 화면에서 카운트다운 시점을 추가 검증해야 합니다.
- 로그인 세션이나 방의 기존 데이터는 서버 버전 업데이트만으로 자동 정리되지 않을 수 있으므로 새 방으로 검증하세요.
- 무료 한도 내 사용을 전제로 합니다. 요금제는 변경하지 않습니다.
- 실제 Cloudflare 배포는 자동으로 수행되지 않았습니다.
